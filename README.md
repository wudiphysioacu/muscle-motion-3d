# muscle-motion-3d

以 3D 模型呈現肌肉在運動時的動作，協助病患理解肌肉的起點、止點與收縮方向。

## 目前狀態

- 本地 repo 已初始化，尚未有模型檔案。
- 製作工具與檔案格式尚未決定。候選方案：Blender 建模、匯出 glTF/GLB，再用網頁 3D 函式庫（例如 three.js）呈現。

## 注意事項

- 本 repo 目前為私人（private）。
- 請勿放入病患個人資料、診療紀錄，或受版權保護的原始教材（例如 PDF 書籍）。`.gitignore` 已排除 PDF 與 `patient-data/` 資料夾。
