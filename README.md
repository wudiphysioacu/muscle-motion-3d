# muscle-motion-3d

以 3D 模型呈現肌肉在運動時的動作，協助病患理解肌肉的起點、止點與收縮方向。

## 模型列表

| 模型 | 檔案 | 內容 |
|---|---|---|
| 肘關節屈曲 | `models/elbow-flexion/index.html` | 肱二頭肌（長頭、短頭）、肱肌、肱三頭肌（長頭、外側頭）；動畫顯示收縮變短變粗、拮抗肌被拉長；點選肌肉可看起點、止點、作用、神經支配與常見疼痛位置 |

## 怎麼開啟

模型是單一網頁檔，用 three.js（從網路 CDN 載入）即時繪製，所以開啟時需要網路。

1. 在這個資料夾執行 `python3 -m http.server 8765`
2. 用瀏覽器打開 `http://127.0.0.1:8765/models/elbow-flexion/`

直接雙擊 HTML 檔通常也能開，但部分瀏覽器會擋住本機檔案載入模組，用上面的方式最穩定。

## 製作方式

- 骨骼與肌肉以程式產生（不使用外部模型檔），肌肉沿起點到止點的路徑生成，長度改變時依體積守恆自動變粗或變細。
- 屈肘時主動肌的發光強度隨重力力矩（約與屈肘角度的正弦成正比）變化，90° 時最強。
